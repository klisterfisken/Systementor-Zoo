# Systementor Zoo

An early practice assignment from the frontend curriculum, built to train HTML and CSS fundamentals. The brief was to design a website for a fictional zoo, showcasing a handful of animals with images, quick facts, and links to learn more.

## Features

- A hero section with a looping background video
- An animal gallery with photos and a quick-facts table linking out to Wikipedia
- An embedded Google Maps location
- Fully responsive layout

## Built with

- Semantic HTML
- CSS — no framework. Styled using custom properties for colors, flexbox and grid for layout, and media queries for responsiveness
- Google Fonts (Coiny, Quicksand) and Font Awesome for icons

No JavaScript was used — this exercise was scoped to HTML and CSS only.

## Known issues

- Navbar buttons wrap awkwardly outside of desktop view
